Este proyecto utiliza la skill `frontend-design` para garantizar una calidad visual superior.

## Directrices Principales

1. **Pensamiento de Diseño**:
   - Antes de codificar, elegir una dirección estética clara (minimalista, maximalista, retro-futurista, etc.).
   - Buscar que la interfaz sea MEMORABLE y UNICA.

2. **Tipografía**:
   - Evitar fuentes genéricas (Arial, Inter, Roboto).
   - Usar combinaciones de fuentes con carácter (ej. Google Fonts distintivas).

3. **Color y Movimiento**:
   - Paletas cohesivas con acentos fuertes.
   - Micro-interacciones suaves y animaciones de entrada orquestadas (staggered reveals).

4. **Composición Espacial**:
   - Layouts inesperados, asimetría, uso generoso del espacio negativo o densidad controlada.

5. **Detalles Visuales**:
   - Gradientes complejos, texturas de ruido, sombras dramáticas y bordes decorativos.

## Aplicación en el Proyecto
Siempre que se cree o modifique un componente de UI, se deben aplicar estos principios para elevar el diseño por encima del estándar "genérico de IA".
